# 🤖 Smart Matcher - Analisador de Vagas com IA

Ferramenta automatizada desenvolvida em Python para analisar a compatibilidade entre perfis profissionais e descrições de vagas de tecnologia (como o iFood), gerando relatórios de match estratégico e direcionamentos para entrevistas.

## 🚀 Tecnologias Utilizadas
- **Python 3.13**
- **Google GenAI SDK**
- **Sistema de Fallback Inteligente (Anti-queda):** Garante estabilidade operacional e continuidade da análise mesmo se houver interrupções ou instabilidades na API de IA.
